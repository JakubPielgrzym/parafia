📝 Jak aktualizować treści
Ogłoszenia parafialne
Znajdź w index.html sekcję <section id="ogloszenia"> i edytuj tekst wewnątrz <div class="announcement-body">.
Aktualności
W sekcji <section id="aktualnosci"> edytuj karty <article class="news-card">.
Porządek Mszy
W sekcji <section id="msze"> zmień godziny w <ul class="mass-list">.
Dane kontaktowe
W sekcji <section id="kontakt"> zaktualizuj telefon, e-mail itp.
🚀 Jak wdrożyć zmiany na GitHub Pages
Wejdź w plik na GitHubie i kliknij ołówek (Edit this file).
Wprowadź zmiany.
Przewiń na dół, wpisz krótki opis zmiany (np. "Aktualizacja ogłoszeń").
Kliknij Commit changes.
Strona zaktualizuje się automatycznie w ciągu 1–2 minut.
